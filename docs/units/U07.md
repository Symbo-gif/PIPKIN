## Scope

Main screen: pet viewport (placeholder art OK), five meters, actions Feed / Clean / Sleep / Play / Pet.

- Feed: quick-feed applies a `:core` hunger restore (default +20 hunger, clamp 100) until U8 exists; then Feed can route to mini-game.
- Other actions call `:core` care functions (define in this unit if missing: `CareActions`).
- ViewModel loads/saves via repository; runs reconcile on start.
- No simulation math in Composables.

## Out of scope

Mini-game screens (U8/U9), onboarding (U11), death screen (U10 can stub a callback).
