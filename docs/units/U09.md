# U9 — Mini-game 2: reaction / timing

**Depends on:** U7  
**Branch:** `feature/U09-minigame-reaction`  
**Modules:** `:app` `com.pipkin.ui.minigames`  
**Risk:** Low–Medium

## Scope

Wait for a visual tell, tap inside the success window.

- Success: happiness up (default +15), energy down slightly (default -5).
- Miss: no happiness gain (or small), no death.
- Same layering as U8: result object → `:core` / ViewModel.

## Tests

- Window hit/miss scoring is deterministic given timestamps.
- Result applied once.
- Instrumented: control to complete a forced-success path in tests (debug hook or fake engine).
