# U6 — Notification layer (standard + Live Update)

**Depends on:** U5  
**Branch:** `feature/U06-notifications`  
**Modules:** `:app` `com.pipkin.notifications`  
**Risk:** High (churn)

## Scope

- Channels: critical care, general status.
- Standard notification for: care-mistake imminent/fired, death imminent, pet died.
- Live Update / ongoing status where API allows: one updating notification with current meters, not a new notification each tick.
- Dedupe: same condition does not re-notify until it clears then reoccurs.
- Taps open the main pet screen (deep link later if needed).
- No repeat non-actionable spam (audit focus).

## Out of scope

Firebase (U12).

## Tests

- Posting critical notification when `CheckResult` says care mistake fired.
- Deduping: second identical result does not post again.
- Live update path updates in place (can be unit-tested against a fake `NotificationPoster`).
- No notification for a healthy no-op worker result.
