# U8 — Mini-game 1: Catch the Food

**Depends on:** U7  
**Branch:** `feature/U08-minigame-catch-food`  
**Modules:** `:app` `com.pipkin.ui.minigames`  
**Risk:** Low–Medium

## Scope

Compose mini-game: food falls, player taps/drags to catch within a time limit.

- Success: `:core` care result increases hunger (default +15 to +25 by catch count) and a little happiness. Clamp 100.
- Failure / quit: small or zero hunger gain; never lethal.
- Return to main pet screen with updated meters.
- Game UI does not mutate meters directly.

## Tests

- Scoring function (pure, preferably in `:core` or a JVM-testable mapper): N catches → expected hunger delta.
- UI: start, catch one, finish, ViewModel applies result once.
- Double-submit of the same result is ignored.
