# U4 — Evolution branching & care-mistake tracking

**Depends on:** U2  
**Branch:** `feature/U04-evolution-care`  
**Modules:** `:core` `com.pipkin.core.evolution`  
**Risk:** Critical (safety-critical feel)

## Scope

Care mistake: increment `careMistakeCount` at **exactly 20 minutes** of continuous hunger == 0. Use `hungerZeroSinceMillis`. After a mistake, do not increment again until hunger > 0 (reset `hungerZeroSinceMillis` to null) and hunger returns to 0 for another 20 minutes.

Evolution stages and branches per `docs/build-plan.md` §3.3. Age from `createdAtMillis` vs simulated time (`lastSimulatedAtMillis`). Branch at Child→Teen and Teen→Adult from mistake count + average meter health (define thresholds in Session 1 plan; defaults: 0 mistakes and avg meters ≥ 60 → Kindred; ≥ 3 mistakes or avg < 30 → Withered; else Wild).

Must be invoked from the tick/reconcile pipeline so offline catch-up also accrues mistakes and evolutions (integrate with U2/U3 APIs; do not duplicate decay math).

## Out of scope

Death UI (U10), sprites (U7).

## Tests

- `care_mistake_triggers_at_exactly_20_minutes_of_zero_hunger`
- `care_mistake_does_not_trigger_at_19_minutes`
- `care_mistake_does_not_double_count_while_hunger_remains_zero`
- Stage transitions at Egg 24h, Child 3d, Teen 4d
- Branch selection table tests for Kindred / Wild / Withered

Mandatory Critical re-audit even if clean. Coverage ≥ 90% evolution package.
