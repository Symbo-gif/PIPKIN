# U10 — Death, rebirth, pet history log

**Depends on:** U4, U7  
**Branch:** `feature/U10-death-rebirth-history`  
**Modules:** `:core` death rules + `:app` `com.pipkin.ui.history`  
**Risk:** High

## Scope

- Death when health == 0 or hunger has stayed 0 for 24 simulated hours after a care mistake in that episode (build plan §3.1). Set `isDead`, freeze further decay.
- Death screen in Compose before rebirth is available.
- Rebirth: new `petId`, egg stage, meters reset, same slot; append `HistoryLog`.
- History list UI for the slot (previous pets).

## Tests

- `pet_dies_when_health_reaches_zero`
- `pet_dies_after_24h_hunger_zero_following_care_mistake`
- Dead state does not continue decaying meters
- Rebirth creates a new pet id and history row
- Instrumented: death screen appears when ViewModel state is dead
