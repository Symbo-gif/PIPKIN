# U5 — WorkManager periodic checks & AlarmManager critical alerts

**Depends on:** U3  
**Branch:** `feature/U05-background-work`  
**Modules:** `:app` `com.pipkin.work`  
**Risk:** Medium

## Scope

- Periodic `CoroutineWorker` (15–30 min flex) that loads active slot, runs `OfflineReconciler`, persists, and returns success/retry.
- AlarmManager (exact or windowed per API level) scheduled when hunger is 0 and the 20-minute care-mistake deadline is in the future, and when death clock is approaching (from build plan). Cancel when condition clears.
- Constraints: no main-thread I/O. Worker is testable with a fake reconciler.

## Out of scope

Notification UI/copy (U6). Worker may expose a `CheckResult` that U6 consumes.

## Tests

- Worker invokes reconciler and persists returned state (instrumented or Robolectric).
- Alarm scheduled when hunger-zero window is active; cancelled when hunger > 0.
- Periodic work unique name so it is not duplicated.
