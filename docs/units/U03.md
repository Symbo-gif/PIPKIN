# U3 — Offline-progress reconciliation

**Depends on:** U2  
**Branch:** `feature/U03-offline-reconciliation`  
**Modules:** `:core` `com.pipkin.core.offline`  
**Risk:** Critical (safety-critical feel)

## Scope

`OfflineReconciler.reconcile(state, nowMillis): PetState`

- `elapsed = nowMillis - state.lastSimulatedAtMillis`
- Simulated duration = `min(elapsed, 72 hours in millis)`
- A **96 hour** real gap therefore simulates **72 hours**
- Delegate tick application to U2's engine for that simulated duration
- Negative elapsed (clock rollback) is corrupt input: do not apply ticks; return state unchanged or typed error (choose in plan; prefer typed error)
- Future `lastSimulatedAt` same as rollback
- Deterministic and side-effect free

Mandatory property/fuzz tests over elapsed ∈ [0, 200h], meter extremes, cap boundary 72h ± 1ms.

## Out of scope

WorkManager (U5), notifications (U6).

## Tests

- `offline_gap_of_96_hours_capped_at_72_hours_simulated`
- `offline_gap_of_72_hours_simulates_exactly_72_hours`
- `offline_gap_under_cap_simulates_full_elapsed`
- Property: simulated hours never exceed 72
- Property: hunger after catch-up equals engine(state, simulatedDuration)
