# U11 — Onboarding + save-slot wiring

**Depends on:** U1, U7  
**Branch:** `feature/U11-onboarding-saves`  
**Modules:** `:app` `com.pipkin.ui.onboarding` + data  
**Risk:** Medium

## Scope

- First launch: onboarding (name pet, choose slot 0–2, hatch).
- Slot picker: three slots, occupied vs empty, switch persists current first.
- Corrupt save: recovery UI (reset slot or discard) using U1 failure types.
- Active slot stored in DataStore or similar (not a hardcoded 0).

## Tests

- Hatch writes PetState to chosen slot.
- Switching slots persists A then loads B.
- Empty slot shows empty state.
- Instrumented onboarding happy path.
